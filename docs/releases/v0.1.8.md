# Lenso Agent v0.1.8

This prerelease packages the merged Web onboarding and conversation improvements
required by the one-command Agent Console distribution.

- Keep the Web surface available before ChatGPT authentication, so users can
  sign in from Console. Browser loopback callbacks support IPv4 and IPv6.
- Preserve active runtime and conversation history across recoverable management
  and Tool failures.
- Persist message attachments and native image input, editable Profile drafts,
  explicit Profile revisions, per-turn approval modes, selected Skills and
  context, and durable branches from completed conversation turns.

All five entrypoints are distributed for Apple silicon macOS and x86-64 Linux
with SHA-256 checksums and GitHub provenance. Existing Agent Home, credentials,
Profiles, Tool policy, and Session data remain in place. The Session schema
includes the merged Session 1.8 changes; this release does not promise that older
binaries can read newly written Session data. No tool grants are added by the
installer. npm Console distribution remains a separate Console-owned workflow.
