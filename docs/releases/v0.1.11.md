# Lenso Agent v0.1.11

## Highlights

Use one terminal command for interactive coding, headless tasks, and management:

```sh
lenso-agent auth login
lenso-agent profiles install coding
lenso-agent --profile code
lenso-agent run --profile plan "Summarize this workspace"
lenso-agent sessions list
lenso-agent doctor
lenso-agent acp
```

The default command opens the TUI. `run` explicitly executes a headless task;
command-shaped prompts remain task text. ACP requires the optional ACP component.

## Compatibility

CLI, TUI, and ACP keep independent process-owning surfaces and Host Catalogs.
The entrypoint dispatches to exact sibling executables with inherited workspace,
environment, standard streams, signals, and exit status. Install matching
components together; `--component agent` now includes its CLI companion.
Existing `lenso-agent-cli` scripts remain supported, along with explicit
`lenso-agent cli` and `lenso-agent tui` aliases.

Homebrew and npm consumers must update their pinned native cohort before these
commands become available through those distributions.
