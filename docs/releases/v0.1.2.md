# Lenso Agent v0.1.2

This prerelease lets a separately running Console Agent discover and invoke
business Tools from its managed App Agents. Tool catalogs are frozen to the
target Agent Generation, namespaced by Agent identity, and filtered by the
target policy before they become model-visible.

Execution remains on the App Agent data plane. The target Agent continues to
own Tool Hooks, credentials, authorization, and business policy, while stale
catalogs fail closed instead of being replayed against a changed Generation.
The Console integration is a removable Tool Provider and does not expose an
App Agent's Host control plane to the model or browser.

The release includes `lenso-agent-web` and `lenso-agent-console-web` for Apple
silicon on macOS 15 or later and x86-64 Linux. Every archive has a sibling
SHA-256 record and build-provenance attestation.
