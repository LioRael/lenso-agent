# Lenso Agent v0.1.9

This prerelease adds browser-authorized Projects business connections. Enable a
Business App connection in the Agent Plugin Root, sign in through Console and
approve the App's narrowed scope. Tool descriptions are available before login;
execution uses the business account captured when the Turn starts.

- Complete browser consent in a Plugin-managed task, including after leaving or
  reloading Connections. Reopening sign-in resumes a pending attempt; cancellation
  and Plugin shutdown stop it.
- Keep business credentials in provider memory, outside model inputs, Session
  history and Plugin configuration. Restart requires a new connection.
- Preserve an active Turn's identity across account switches and local
  disconnects. The business App still enforces expiry, revocation, Organization
  membership, Team visibility and operation scope on every request.
- Preserve native Tool target context and cancellation through Turn admission.
  Do not automatically retry potentially completed business mutations.
- Include a reproducible local PostgreSQL acceptance App and protocol verifier.
  Separate real Console/model validation confirmed an Issue title update and its
  signed-in actor in the database.

The linked connection is optional and grants no tools by default. It requires a
business App exposing the documented Auth consent and Projects ingress Plugins;
this release does not deploy that App. Console UI and npm packages are released
separately by the Console repository.

All five entrypoints are packaged for Apple silicon macOS and x86-64 Linux with
SHA-256 checksums and GitHub provenance. Installation preserves Agent Home and
does not change existing Tool grants or credentials.
