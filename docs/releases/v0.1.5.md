# Lenso Agent v0.1.5

This prerelease keeps a model transport failure within the current Turn, so a
WebSocket connection failure or interrupted response no longer retires the active
Agent Generation and blocks later requests until restart.

- Model domain failures remain explicit Turn failures with bounded, sanitized
  reason codes. Session failure records preserve the provider reason code.
- A WebSocket receive failure discards its socket and continuation checkpoint.
  Sent requests, partial output, failed Turns, and Tool effects are never
  automatically replayed. The existing bounded pre-send retry stays unchanged.
- Agent Descriptor 3.1 retains `lenso.agent@3` and adds `model_failure`; existing
  consumers retain the unknown-domain-error compatibility path.
- Existing SQLite-managed Homes, imported Profiles, Tool policies, and Sessions
  remain owned by their current authorities. Upgrading does not grant Tools.

All five entrypoints are distributed for Apple silicon macOS and x86-64 Linux,
with SHA-256 checksums and GitHub build provenance. Install the matching Web and
Console Web binaries when using the source-distributed Console 1.3.0.

This release fixes failure escalation, not network availability. A failed Turn
may have completed Tool effects; review its durable history and workspace before
starting a new request. No transparent fallback or replay is added.
