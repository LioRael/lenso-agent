# Lenso Agent v0.1.13

App Plugins can author Agent Tool providers through optional TypeScript and Rust
conventions. Providers use normal capability discovery and explicit Tool policy;
adding a source file does not grant execution authority. The example acceptance
flow verifies discovery, allowed execution, denial before execution and removal
using a fixture Model. Rust keeps the same `plugin`, `tool_provider`, and
`tool` macros while the convention packages one source into both Wasm and
Process implementations.

An App build can also publish a hashed `lenso.agent.deployment@1` resource.
`lenso-agent dx check --from <app-dist>` validates it without touching an Agent
Home; `lenso-agent dx apply --from <app-dist>` explicitly stages it into an
unmanaged Home. The generated Provider stays disabled for the default Agent,
and only an authored Profile with an explicit Tool allowlist can select it.

Bun providers receive their admitted generation artifacts and Authoring V2 codecs.
The released Bun Adapter fixes synchronous startup inside an asynchronous Host.
