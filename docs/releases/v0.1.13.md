# Lenso Agent v0.1.13

App Plugins can author Agent Tool providers through optional TypeScript and Rust
conventions. Providers use normal capability discovery and explicit Tool policy;
adding a source file does not grant execution authority. The example acceptance
flow verifies discovery, allowed execution, denial before execution and removal
using a fixture Model.

Bun providers receive their admitted generation artifacts and Authoring V2 codecs.
The released Bun Adapter fixes synchronous startup inside an asynchronous Host.
