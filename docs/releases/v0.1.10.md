# Lenso Agent v0.1.10

## Highlights

- Business connections now expose non-secret account identity, expiry and reconnect state.
- Issue Tool results include safe links back to the configured business App.
- A 401 invalidates only the delegated grant used by that Turn, preserving a newer account connection.
- The Projects acceptance fixture is pinned to merged Auth, Projects and Projects Web sources.

## Acceptance

The release source passed the full Agent workspace suite and real PostgreSQL Projects acceptance.
The native Console acceptance additionally proved Projects as a removable far-left Workspace with
its own context sidebar, browser consent, project creation, Issue/activity reads, Console-native
navigation, mini Agent access, cross-organization denial, fixed App destination and no browser
credential exposure. These acceptance flows call the real protocols without invoking a model.

## Compatibility

Existing providers that omit optional account metadata remain supported. Console distributions
must update their pinned Agent cohort before they can expose the new runtime behavior.
