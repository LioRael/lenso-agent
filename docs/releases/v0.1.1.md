# Lenso Agent v0.1.1

This prerelease adds the loopback Agent Web API as a supported binary release
boundary. Consumers such as Lenso Console can run the reviewed Agent
composition without linking the Agent workspace's private Rust crates.

The default installer now installs `lenso-agent-web` and
`lenso-agent-console-web` alongside the interactive Agent and management CLI.
The separate process entrypoints keep the default and Console Plugin inventories
isolated while exposing neither internal Rust composition as a library
dependency. An explicit
`--managed-agent ID=URL` grants that Console Agent access to a loopback App
Agent's configuration and package-lifecycle control planes; no target Host
credentials or `/control` authority are exposed to the browser. ACP remains an
independent optional component.

Supported release targets remain Apple silicon on macOS 15 or later and
x86-64 Linux. Every archive has a sibling SHA-256 record and build-provenance
attestation. Agent Home remains preserved across upgrades and ordinary
uninstallation.
