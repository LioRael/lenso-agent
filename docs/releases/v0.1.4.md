# Lenso Agent v0.1.4

SQLite-managed Agent Homes can now import the official Plan, Code, and Code
Sandbox Profiles while Agent Web continues running:

```sh
lenso-agent-cli profiles import coding \
  --url http://127.0.0.1:8788/api/console/v1/agent
```

Use the running Host's `LENSO_AGENT_CONTROL_TOKEN`. Imports are revision-fenced,
reject customized file replacement, and recover interrupted materialization from
SQLite evidence. Imported Profiles survive restart; activation remains a separate
Ready Gate operation that preserves the previous mode on failure.

Profile switches update Bootstrap mode, available Tools, and managed configuration
publication receipts. Existing Tool grants remain unchanged; newly available
Tools require explicit authorization through the configured Tool policy.

Offline installation into managed Homes remains blocked. Remote/injected
configuration authorities and arbitrary custom Profile uploads are not supported
by this import. Keep Agent Home outside the source Workspace for Code worktree
isolation, and install the required coding programs before selecting Code.

All five independent entrypoints are available for Apple silicon macOS and
x86-64 Linux, with SHA-256 checksums and GitHub build provenance.
