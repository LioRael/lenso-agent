# Lenso Agent v0.1.6

This prerelease stabilizes coding workflows across Profile switches, parallel
Tools, and Codex SSE failures.

- Switching Plan to Code refreshes the existing Session's system instruction
  while preserving each active Turn's Generation-bound Profile metadata.
- SQLite-managed coding Profile import is available only when the Host contains
  the required Plugins. Minimal Console Hosts reject unsupported imports.
- Parallel coding Tools share sufficient provider admission capacity instead of
  cancelling a Turn when git and read operations run together.
- SSE body failures, malformed frames, and premature EOF fail only the current
  Turn. The Session and Generation remain available for an explicit next request.
  Invalid Tool arguments are returned to the model for correction within the
  existing Turn limits.
- Installer help derives its displayed version from the release default.

All five entrypoints are available for Apple silicon macOS and x86-64 Linux,
with SHA-256 checksums and GitHub build provenance. Existing SQLite configuration,
imported Profiles, Tool policy, and Sessions are preserved by upgrades.

A real Codex SSE Session completed Plan, Code, checkpoint, edit, and diff review.
This release does not guarantee external network availability or automatically
replay sent requests, partial output, or Tool effects. No additional Tool grants
are introduced by upgrading.
