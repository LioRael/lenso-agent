# Lenso Agent v0.1.3

This prerelease completes the reviewed local coding and portable Tool Plugin
workflows. Parallel approval-backed Tool calls queue at the approval Hook and
retain independent decisions. Coding Profile installation rejects managed Homes
before writing, and Web advertises named Profile selection only under the
supported local Plugin Root authority.

The Wasm Adapter now admits dependency-free authoring v2 Contracts using its
existing runtime profile. Portable Bundles combining Wasm and Process require
Lenso CLI 0.5.2 or later for packaging and lifecycle management. Install the
Bundle, configure its Instance, and explicitly grant its Tools before invoking
it; the updated portable example documents that sequence.

SQLite-managed Profile hot import remains unsupported. Install coding Profiles
into a fresh local-authority Home before starting the Host. Existing managed
Homes retain their authority guard after shutdown.

Archives include the terminal, CLI, ACP, App Web and Console Web entrypoints for
Apple silicon macOS and x86-64 Linux, with SHA-256 records and build provenance.
