# Lenso Agent v0.1.0

This first prerelease makes Lenso Agent installable without a Rust toolchain.

> [!WARNING]
> The macOS artifact is not platform-signed. Verify its SHA-256 and GitHub
> build-provenance attestation before use.

Supported release targets:

- Apple silicon on macOS 15 or later (`darwin-aarch64`); and
- x86-64 Linux (`linux-x86_64`).

The default installer adds the interactive `lenso-agent` product entrypoint and
the `lenso-agent-cli` management and headless entrypoint. The ACP binary remains
an independent optional component for ACP-compatible editors.

After installation:

```sh
lenso-agent-cli auth login
lenso-agent-cli profiles install coding
lenso-agent-cli doctor
lenso-agent --profile code
```

Every archive has a sibling SHA-256 record, the assembled release includes
`SHA256SUMS`, and GitHub publishes build-provenance attestations for release
archives. Agent Home is preserved across binary upgrades and ordinary
uninstallation.

The direct ChatGPT subscription provider remains experimental because its
upstream surface can evolve. The API-key-compatible Model Plugin remains the
stable alternative. Windows binaries and Intel macOS binaries are not included
in this prerelease.
