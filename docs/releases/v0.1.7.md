# Lenso Agent v0.1.7

This prerelease exposes the Agent working directory to Console task views.

- Web bootstrap includes optional read-only `workspace.path`, captured from the
  Host process when its runtime starts.
- Console can display the selected Agent's actual directory alongside task
  creation, history, and recorded Changes. The metadata does not change a
  process directory, bind historical Sessions, or grant Tool access.
- Clients without workspace support remain compatible. The field is omitted
  when the directory cannot be read or represented as UTF-8.

All five entrypoints are distributed for Apple silicon macOS and x86-64 Linux
with SHA-256 checksums and GitHub build provenance. Upgrading replaces binaries
and preserves Agent Home, SQLite configuration, Profiles, Tool policy, and
Session history. No storage migration or additional Tool grants are introduced.
